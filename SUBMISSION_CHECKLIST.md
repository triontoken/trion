# TRION Indexing Submission Checklist

## Ready now

- Official mint published consistently
- Fixed supply and mint-authority proof published
- Website live in English and Russian
- Whitepaper v1.0 published
- X, Telegram, GitHub, and project email live
- 256 x 256 wallet logo under 100 KB
- 512 x 512 high-resolution logo
- Metaplex-compatible metadata JSON
- Trust Wallet-style `info.json` and folder structure

## Before each submission

- Confirm every public URL returns successfully
- Confirm the complete mint address, not only the symbol
- Confirm current supply and authority fields on-chain
- Use `assets/logo.png` for 256 x 256 upload fields
- Use `assets/logo-512.png` only where files above 100 KB are accepted
- Use the official website and social accounts for ownership verification
- Keep screenshots or transaction receipts for paid submissions

## Recommended sequence

1. Publish this package in the official GitHub repository.
2. Verify raw GitHub URLs for the logo and metadata.
3. Confirm the on-chain metadata URI and decide whether an update is needed.
4. Request free or organic indexing first.
5. Submit to market-data services after reliable liquidity and trading data exist.
6. Submit to paid wallet repositories only after checking current eligibility and fees.

## Important

Do not claim that TRION is verified, listed, audited, liquid, locked, or vested until the relevant public source independently confirms it.
